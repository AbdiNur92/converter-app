# Lexicon Converter App

A console unit converter: pick a converter from the menu, enter a value,
get a formatted result, and keep going until you choose Exit.

## Converters

1. Temperature (°C ↔ °F)
2. Currency (SEK → USD, SEK → EUR)
3. BMI calculator

## Run it

Open `src/main/java/se/lexicon/ConverterApp.java` in IntelliJ and click ▶ next to `main`.
